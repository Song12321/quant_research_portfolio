**结论**
本地市场数据主要是**保留 Tushare 原始单位的数据**，不是已经统一成“元、股、小数比例”的数据。单位转换主要发生在因子计算层，而且**只转换了部分字段**。

本次只读审视了实际数据目录 [market_data](D:/lqs/quantity/market_data)、下载及加载代码，并直接访问了 Tushare 官方文档；未修改代码或数据。

**1. 哪些字段涉及单位**
以下转换以内部统一使用“元、股、小数比例”为前提，不代表必须修改原始文件。

| 接口 / 本地数据 | 字段 | 接口单位 → 统一单位 |
|---|---|---|
| `daily` | `amount` | 千元 → 元，×1000 |
| `daily` | `vol` | 手 → 股，×100 |
| `daily` | `pct_chg` | % → 小数，÷100 |
| `daily_basic` | `total_mv、circ_mv` | 万元 → 元，×10000 |
| `daily_basic` | `total_share、float_share、free_share` | 万股 → 股，×10000 |
| `daily_basic` | `turnover_rate、turnover_rate_f、dv_ratio、dv_ttm` | 百分数口径 → 小数，÷100 |
| `index_daily` | `amount、vol、pct_chg` | 分别为千元、手、% |
| `sw_daily` | `amount、float_mv、total_mv` | 万元 → 元，×10000 |
| `sw_daily` | `vol` | **万股** → 股，×10000 |
| `hm_detail` | `buy_amount、sell_amount、net_amount` | 已是元，不转换 |
| `margin_detail` | `rzye、rqye、rzmre、rzche、rzrqye` | 已是元，不转换 |
| `margin_detail` | `rqyl、rqchl、rqmcl` | 股票标的按股；其他标的需区分份、手 |
| `dividend` | `cash_div、cash_div_tax` | 每股现金分红，不是每10股 |
| `dividend` | `stk_div、stk_bo_rate、stk_co_rate` | 每股送转比例，不是百分数 |
| `dividend` | `base_share` | 万股口径；本地文件未包含此字段 |

官方依据：[日线](https://tushare.pro/document/2?doc_id=27)、[每日指标](https://tushare.pro/document/2?doc_id=32)、[指数日线](https://tushare.pro/document/2?doc_id=95)、[申万日线](https://tushare.pro/document/2?doc_id=327)、[游资](https://tushare.pro/document/2?doc_id=312)、[两融](https://tushare.pro/document/2?doc_id=59)、[分红](https://tushare.pro/document/2?doc_id=103)。每日指标文档当前未明确给换手率标 `%`，其百分数口径另经本地量股关系验证。

财务类需要单独对待：
- `income、cashflow、balancesheet` 的金额字段，本地数值支持**元口径**；每股收益为元/股。官方页面不少字段没有逐项标单位，不能声称全部得到文档明确确认。[利润表](https://tushare.pro/document/2?doc_id=33)、[现金流量表](https://tushare.pro/document/2?doc_id=44)、[资产负债表](https://tushare.pro/document/2?doc_id=36)
- `balancesheet.total_share` 本地为**股量级**，与 `daily_basic.total_share` 的**万股**不同。
- `fina_indicator` 混合金额、每股指标、百分数、倍数、天数，**不能整表统一缩放**。例如本地 `debt_to_assets=96.4335` 是百分数，而 `debt_to_eqt=27.0386` 是倍数。[财务指标](https://tushare.pro/document/2?doc_id=79)
- `index_weight.weight` 文档仅写“权重”；本地同日权重合计约100，支持百分数口径，作为组合权重使用时需÷100。[指数权重](https://tushare.pro/document/2?doc_id=96)

**2. 本地究竟转换过没有**
**市场数据文件：已检查的写入链路没有单位缩放。** 下载和增量更新主要直接保存接口数值，另做日期处理、合并、去重。因此更准确地说是“保留接口单位的整理数据”，不是完全未经处理的原始响应。见 [下载器](D:/lqs/codeAbout/py/Quantitative/stock/quant_research_portfolio_simplify/quant_lib/tushare/data/downloader.py:487)、[更新器](D:/lqs/codeAbout/py/Quantitative/stock/quant_research_portfolio_simplify/quant_lib/tushare/data/market_data_updater.py:101)。

实际数值核验：
- 对2020、2025、2026年日线检查：有效记录的 `amount×1000÷(vol×100)` 均落在当天高低价区间内，容差0.02元，支持原始“千元、手”口径。
- 2025年匹配数据中，`total_mv≈close×total_share`，相对误差中位数约 `1.57e-11`；`turnover_rate≈vol/float_share`，比值中位数为1，支持“万元、万股、百分数”的组合。
- 2025年 `daily_hfq` 与 `daily` 匹配645,612行，成交量、成交额全部数值一致。**后复权的是价格，不代表成交量已经换成股或成交额已经换成元。**
- 财务样本中，`净资产÷total_share≈bps`、`总负债÷总资产×100≈debt_to_assets`，支持上述不同单位判断。

**因子计算层：部分已经转换。** 见 [基础换算](D:/lqs/codeAbout/py/Quantitative/stock/quant_research_portfolio_simplify/projects/_03_factor_selection/factor_manager/factor_calculator/factor_calculator.py:1881)。

| `get_raw_factor()` 字段 | 返回口径 |
|---|---|
| `total_mv、circ_mv` | 已×10000，为元 |
| `amount` | 已×1000，为元 |
| `vol_raw` | 已×100，为股；名字中的 raw 不代表接口单位 |
| `turnover_rate` | 已÷100，为小数比例 |
| `pct_chg` | 由后复权收盘价重新计算，为小数收益率 |
| `dv_ttm` | **未÷100，仍是百分数** |
| `vol_hfq` | 已转换成股后，再除以后复权乘数的派生量 |

**3. 需要注意的风险**
1. **同名字段不同单位：** `get_raw_field('amount')` 仍是千元，而 `get_raw_factor('amount')` 已是元；重复转换会放大1000倍。
2. **跨表字段冲突：** `total_share` 同时存在于股本日指标和资产负债表，但加载器未给它明确限定来源，而是首次登记优先，存在来源及单位歧义。见 [字段映射](D:/lqs/codeAbout/py/Quantitative/stock/quant_research_portfolio_simplify/quant_lib/data_loader.py:119)。
3. **百分数尚未统一：** `dv_ttm` 保留百分数，而收益率、换手率因子已经是小数；不能直接按同一尺度进行金额计算或绝对阈值比较。见 [股息率加载](D:/lqs/codeAbout/py/Quantitative/stock/quant_research_portfolio_simplify/projects/_03_factor_selection/factor_manager/factor_calculator/factor_calculator.py:195)。

边界：本地未发现 `margin_detail` 的 Parquet 文件，只核对了其官方契约；其他结论基于写入代码、文件结构和上述数值检查，未逐字段逐历史记录与在线 API 对账。**目前不应对整个数据目录统一乘除某个倍数。**
